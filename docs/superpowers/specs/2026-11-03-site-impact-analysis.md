# 现场条件与施工影响分析扩展

日期：2026-11-03。依据用户明确指示及《分析图纸及施工影响》对话的成果形式，对现有事实库流程进行扩展，延续已授权自主执行。

目标：从当前项目的图纸文字、图层、标注坐标和线形证据提炼现场条件、施工影响、建议及待核实事项。不同项目的结论不得互相套用。页面只显示分析入口和结果对话框，详细图元/测量仍在后台归档。

实现：聚合各专业有限文字证据，优先对总平、现状、地形、竖向及室外图选择最多3份原生线形概览。模型结果必须引用当前输入的项目来源。结果保存到项目独立分析版本JSON，并写入“现场条件与施工影响.md”；固定版本保存同一结果。用户核对采用后进入写作事实草稿，发布后沿用现有严格事实引用规则。分析判断和待核实事项随正文引用保留，禁止当作已实测事实。

版本规则：采用请求绑定界面中展示的分析ID；资料变化时禁止采用旧分析。生成新报告不删除已采用旧结论，明确采用新报告后替代旧报告，已发布历史版本不改写。

限制：本版为文字、坐标及部分原生矢量上下文分析，不是完整渲染后的视觉模型识别。复杂嵌套块、代理对象、外参、多视图边界、北向及高程基准仍可能缺失，不能无依据判断实时水位、承载力、管线、作业边界和现场高差。专业结论质量需实际材料核验，不能仅用接口成功表示与参考人工审图完全等效。

验证：新增来源校验、报告保存/固定版本、采用与多次重分析、跨窗口报告ID、资料变更失效测试。独立审查发现的历史结论复活和采用未绑定报告问题纳入回归；前端移除图纸明细及原文MD入口，仅保留单项出处文件名。


验收记录：后端70项、前端3项测试通过，Vite构建通过。真实模型在8192输出额度下finish_reason=stop，汇集8张图纸文字、3张优先图纸原生线形概览及371条证据，得到6项有效分析；剔除一项模型占位内容并记录限制。逐项核对主要DWG/补疑出处。浏览器已显示结果对话框。

复审修复：最新采用报告独立于最新生成报告选择，防止更早被替代结论复活；采用请求绑定界面报告ID，防止多窗口误采用；隐藏全部图纸原始MD及测量入口。对应测试先失败再通过。
