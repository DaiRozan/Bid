## 导入和来源

保留每个压缩包及每个成员文件，记录完整归档路径、SHA256、类型和大小；同一项目重复导入相同内容不重复制造资料。重解析复用稳定资料标识，不删除已确认事实、人工要求或已发布版本。所有成员路径预检，拒绝绝对路径、父目录、符号链接、加密归档及超出嵌套/总量限制的包；不执行归档内程序。独立文件错误保留原件和可见原因，不将整批资料误标为成功。

SQLite 新建独立资料分析/快照表，不破坏现有数据。现有 SourceDocument 可保存成员资料，不修改历史列结构。原件及解析结果在 data/projects/<id>/ 下；Markdown 草稿与发布版按项目隔离。

## 文件解析

- PDF/DOCX 继续保存带页码/段落/表格位置的片段；DOC 使用本机 LibreOffice 隔离配置转换 DOCX。
- XLS 使用 xlrd、XLSX 使用 openpyxl，只读；清单按表头辨认列，跨表保留单位工程、分部、编码、名称、完整项目特征、单位、原始数值/数量，排除汇总表和重复表头；保存工作表、行号。不把空值变成零。
- DWG 使用官方 ODA File Converter 转换副本为 DXF，ezdxf 解析；保留图元 handle、模型/布局、图层、块路径、坐标、文字、属性、标注、图纸单位、外部参照和代理对象情况。支持块变换，不把图纸中的文字当作程序指令。
- 计算对象包括可识别的构件块数量、闭合区域面积、线/折线长度及参数齐全对象的体积。模型空间、布局、图例、详图及同一对象不同视图不能笼统汇总为工程量。计算项须明确计量范围、单位、对象及重复处理；没有这些证据时仅作为图形测量候选，不能声称构件工程量。体积需要明确来源的高度/厚度，不推测。
- CAD 数量保留公式、输入、图元出处、识别规则和复核状态，图形语义不确定、代理对象、单位或尺寸缺失列为待复核，不能伪造完整算量结论。

## 事实库和补疑

草稿按来源写 Markdown，目录包含招标资料、单位工程清单、图纸文字和测量、补疑及未解决问题；结构化 JSON 是同版本的索引，MD 可直接查看。清单明细是可采用的原始项目事实；图纸测量是复核资料。补疑中提取到的修改必须具备原文位置与明确目标；有日期和对应对象才作版本优先比较，不能仅凭文件名字猜日期。补疑不明确时保留原文并标记待确认，发布时显式显示尚未解决问题。

人工可编辑/确认采用事实、明确补疑覆盖目标。发布时构建单一采用值索引，保留覆盖链，不改原始资料。版本目录使用新目录写入，清单/MD/JSON 保存摘要；发布后禁止原地修改或重导入覆盖。读取用于写作时校验文件摘要，发现篡改拒绝生成。旧版本继续可查；新版本发布标记旧章节待复核。

## 写作边界

未发布事实版本时禁止 AI 生成（人工编辑和导出仍可用）。生成和任务重试共用同一准备路径，只向模型传入本项目固定版本的相关事实、要求及章节目标。保存版本引用及事实 ID；禁止未知、跨项目、被覆盖或图纸复核数量作为采用事实。模型须返回类型化 parts 引用，项目数据由后端从固定事实插入；清单字段引用同时保留单位工程、项目名称及数量单位。通用叙述限定从预设方法语句中选择，拒绝任意自由文本及无效引用，失败不增加章节版本。人工编辑保留其人工版本标记。

同时修复已有 DeepSeek JSON 请求缺少 JSON 指令和输出结构的问题，使用响应模型 JSON schema 指导返回，并对正文块做结构校验。

## 页面

“资料与事实”支持完整资料包和单文件，显示目录路径、类型、状态及错误。增加分析资料、查看事实库 MD、核对明细/图纸计算、编辑采用值与补疑覆盖、发布固定版本；显示当前版本、未解析文件和未解决事项。生成按钮依赖发布状态；不把“上传/转换成功”显示为“工程量已核准”。
